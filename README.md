# La fábrica secreta del cardón

Cápsula educativa de fotosíntesis para 1° año, ambientada en el Jardín Botánico de Altura de Tilcara (Pucará de Tilcara, Jujuy).

**Abrir en el navegador:** https://patodoc27.github.io/fabrica-cardon/

- Un solo archivo `index.html` autocontenido: funciona sin internet.
- Recorrido de 8 estaciones (~80 minutos) con actividades guiadas.
- Escenas 3D embebidas (three.js): cardonal, acercamiento hoja → estomas → célula vegetal → cloroplastos. La célula vegetal del nivel 3 usa el modelo de [Cell Architecture Studio / LearningCell](https://github.com/GordenSun/LearningCell).
- El progreso se guarda en la computadora (localStorage).
